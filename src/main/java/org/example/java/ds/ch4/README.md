This repository contains implementations of three Java classes: ArrayMultiset, ExpandableArrayMultiset, and ArrayListFromOne. The project focuses on working efficiently with array-based data structures by adding methods such as removeAll(), trimToSize(), equals(), and compareTo(). The ArrayMultiset class removes elements without preserving order, the ExpandableArrayMultiset class manages unused array space, and the ArrayListFromOne class preserves element order and uses indexing that begins at 1. The project also demonstrates important programming concepts including generics, interfaces, array resizing, object comparison, and efficient algorithm design
