This project contains Java implementations for linked data structures, including a `LinkedMultiset` and a `LinkedListFromOne`. The `LinkedMultiset` class supports adding, removing, counting, and removing all occurrences of elements, while the `LinkedListFromOne` class supports list operations such as adding, removing, setting, searching, adding an array of items to the end, and finding the maximum value. These classes use nodes and references instead of arrays, which helps practice how linked structures work internally. The main focus of this project was to correctly update links between nodes, handle special cases like empty lists, and avoid unnecessary repeated passes through the chain.
