This repository contains Java implementations of recursive algorithms and linked data structures. The project includes methods for recursively checking whether a word contains a q not followed by u, reversing an array in place using recursion, and an optional recursive method for counting positive integers in a linked multiset without creating any additional data structures. It also uses a custom LinkedMultiset implementation built with linked nodes, reinforcing concepts such as recursion, linked lists, base and recursive cases, and writing efficient recursive solutions that preserve the original data structure.
